# Lab 03 · DPO 直接偏好优化

不训奖励模型、不采样、不用 PPO，直接从偏好数据训出对齐后的策略。

```bash
make lab03                              # 原版 DPO，能看到似然位移
make lab03 ARGS="--rpo-alpha 1.0"       # 加 NLL 正则，位移被抑制
make lab03 ARGS="--loss-type ipo"       # 换成 IPO
```

## 损失

```
L = − E[ log σ( β·log(π_θ(y_w|x)/π_ref(y_w|x)) − β·log(π_θ(y_l|x)/π_ref(y_l|x)) ) ]
```

`r̂_θ(x,y) = β·log(π_θ/π_ref)` 就是「隐式奖励」——
论文标题的意思：**你的语言模型偷偷就是一个奖励模型**。

梯度：

```
∇L = −β · E[ σ(r̂_l − r̂_w) · ( ∇log π(y_w) − ∇log π(y_l) ) ]
         └── 自适应权重 ──┘   └ 提高好的 ┘  └ 压低坏的 ┘
```

自适应权重的含义：模型已经判断正确的样本权重趋近 0，**不再贡献梯度** —— 内置的困难样本挖掘。

## 本 lab 的教学重点：似然位移

训练时盯着 `logps/chosen`，你会看到反直觉的现象：

```
step   logps/chosen   logps/rejected   margin   accuracy
   0      -142.3          -145.1         2.8      0.51
 300      -178.4          -201.6        23.2      0.79      ← chosen 也在降！
```

**margin 和 accuracy 都很好看，但 chosen 的概率在下降。**

原因：损失只约束「差值」不约束绝对值，而「压低一个序列」在优化上比
「抬高一个序列」容易得多。被压走的概率质量流向了既不是 chosen 也不是
rejected 的第三类输出（可能是乱码）。这就是 DPO 训久了模型会变傻的机制。

脚本结束时会自动诊断并给出这个数字。用 `--rpo-alpha 1.0` 再跑一遍对比。

## 三个必须注意的坑

1. **log-prob 要求和，不要平均。** 推导里 `log π(y|x) = Σ_t log π(y_t|·)` 就是求和。除以长度会脱离推导（那是 SimPO）。
2. **学习率比 SFT 小 10~40 倍**（`5e-7`）。用 SFT 的 lr 会在 50 步内把模型训废。
3. **必须先 SFT。** 直接在 base 上做 DPO 效果很差 —— 模型连基本格式都不会时，「提高 y_w 相对 y_l 的概率」没有意义。

## 变体

| `--loss-type` | 改动 | 解决什么 |
|:---|:---|:---|
| `sigmoid` | 原版 | 基准 |
| `cdpo` | label smoothing | 标注有噪声时更鲁棒 |
| `ipo` | log-sigmoid → 平方损失 | 防止 margin 被无限推大导致过拟合 |
| `--rpo-alpha` | 加 NLL 正则 | **治似然位移最有效的手段** |
